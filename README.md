## 🎯 How It Works

1. The player selects a cell on the board.
2. The player's move is displayed as **X**.
3. The computer automatically selects an available cell and plays as **O**.
4. The game checks for a winner after every move.
5. If all cells are filled without a winner, the game ends in a draw.
6. The Restart button resets the game.
